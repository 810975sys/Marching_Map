windows
    一、在项目根目录（E:\Marching_Map\）打开终端，执行以下命令：
        ```
        pyinstaller --name MarchingMap --windowed --onedir run.py
        ```
        删除 build/ 和 dist/ 文件夹（避免干扰后续打包），然后用文本编辑器打开 MarchingMap.spec，修改 Analysis 部分的 datas 参数。

        修改后的 .spec 示例（关键部分）：
        python
        # -*- mode: python ; coding: utf-8 -*-

        a = Analysis(
            ['run.py'],
            ……
            binaries=[
                (r'C:\ffmpeg-9.0-essentials_build\bin\ffmpeg.exe', '.'),
            ],  # 将 ffmpeg.exe 随程序一起打包（onedir 模式下会放到 _internal/ 下，运行时通过 sys._MEIPASS / 'ffmpeg.exe' 定位，供 pydub 解码/导出音频）
            datas=[
                ('fields', 'fields'),   # 将 fields 目录整个打包到程序根目录
                ('saves', 'saves'),     # 将 saves 目录整个打包
                # 如果你的程序还用了其他资源（如图标、样式表），也在这里添加
            ],
            ……
        )
        pyz = PYZ(a.pure)

        exe = EXE(
            ……
            console=False,          # 不显示控制台（GUI程序）
            ……
            icon=None,              # 可指定图标，如 'icon.ico'
        )
        coll = COLLECT(……)

        # 注意：项目还通过 Analysis 的 binaries 参数把 ffmpeg.exe 与
        # ffprobe.exe 一起打包（放到 _internal/ 下，运行时用 sys._MEIPASS
        # 定位并配置给 pydub）。pydub 解码用 ffmpeg、探测音频信息用 ffprobe，
        # 两者缺一不可，否则在其他没有安装 ffmpeg 的电脑上会报
        # [WinError 2] 系统找不到指定的文件。
        # 若 ffmpeg 路径变化，需同步修改 MarchingMap.spec 的 binaries 与
        # src/ffmpeg_utils.py 中的 _DEV_FFMPEG_CANDIDATES。
        保存文件。

    二、重新打包
        修改完所有代码后，在项目根目录执行：
        ```
        pyinstaller MarchingMap.spec
        ```
        打包完成后，程序生成在 dist/MarchingMap/ 文件夹中。
