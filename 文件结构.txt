Marching_Map/
│
├─ src/           # 代码目录，存放所有Python源代码（如 code/ 亦可）
│   ├─ main.py    # 主程序入口
│   └─ ...        # 其他模块子目录等
│
├─ fields/        # 预设场地参数，支持多种场地文件（如 .grd、.json、.xml 等）
│   ├─ default.grd    # 默认场地参数
│   ├─ football.grd   # 其他预设场地
│   ├─ ...
│
├─ saves/         # 用户保存的方案，支持自定义路径，默认保存在此
│   ├─ save1/      # 每个保存方案一个子文件夹
│   │   ├─ map.grd    # 保存的场地参数
│   │   ├─ config.json # 保存时的参数配置
│   │   ├─ audio.mp3   # 相关音频（如有）
│   │   └─ ...
│   └─ ...
│
├─ readme.md      # 项目说明文档
├─ Marching_Map.code-workspace # VSCode 工作区配置
├─ 初步构想.txt   # 项目初步构想
├─ 功能.txt       # 功能列表
├─ 架构.txt       # 架构设计

# 说明：
# - src/ 只放Python代码，便于开发、构建和管理。
# - fields/ 只放预设场地参数，便于扩展和切换。
# - saves/ 只放用户保存内容，便于备份和迁移。
# - config/ 放全局配置和默认参数，避免和代码混杂。
# - 其他文档和配置文件放在根目录，便于查阅。
