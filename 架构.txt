根据您的需求，使用 **C++ + Qt** 实现该软件是合理的选择。Qt 提供了强大的图形视图框架（Graphics View Framework）、文档/视图架构、PDF 导出支持、JSON/XML 序列化等能力，非常适合此类可视化编辑类应用。

下面给出一个完整的程序架构分析，包括模块划分、核心类设计、数据流与关键实现要点。

---

## 一、总体架构分层

采用经典的分层架构 + MVC（模型、视图、控制器 model, view, controller）变体（因 Qt 的 Graphics View 本身已包含视图与场景的分离）：

| 层级		| 说明																|
| -------------	| -------------------------------------------------------------------------------------	|
| 表现层 (UI)	| 主窗口、工具栏、时间轴控件、属性面板等，基于 QWidget / QML				|
| 视图控制层	| 图形视图（QGraphicsView）、场景（QGraphicsScene）及其交互逻辑			|
| 业务逻辑层	| 方案管理、拍数计算、点位插值、分组跟随、变换操作等						|
| 数据模型层	| 方案数据（SchemeDocument）、图（SchemeFigure）、点位（PointItem）等	|
| 持久化层	| 保存/加载（JSON/XML）、PDF 导出、图片导出								|

## 二、核心模块划分

### 1. 主控制模块（MainController / MainWindow）
- 负责整体应用生命周期、菜单/工具栏事件分发、各模块协调。
- 持有方案文档对象（SchemeDocument）和当前编辑状态。

### 2. 图形交互模块（基于 Qt Graphics View Framework）
- **Scene（SchemeScene）**：继承 QGraphicsScene，管理所有图元（网格、点位、矩形、文本等）。
- **View（SchemeView）**：继承 QGraphicsView，处理鼠标/键盘交互（框选、拖动画布、缩放、绘制工具等）。
- **自定义图元（CustomGraphicsItem）**：
  - `PointItem`：表示一个点位，含编号、所属组、坐标（场景坐标）。
  - `LineItem`、`RectItem`、`CircleItem`、`ArcItem`、`PolygonItem` 等。
  - `TextNoteItem`：备注文本区域。
- **辅助绘制工具类（DrawingTool）**：根据当前工具模式（点、直线、矩形等）处理鼠标事件，生成对应图元。

### 3. 方案与时间轴模块
- **SchemeDocument**：整个方案的数据容器，包含：
  - 场地设置（`FieldSettings`）
  - 拍数序列（`QList<int> beatsBetweenFigures`）
  - 方案图列表（`QList<SchemeFigure> figures`）
- **SchemeFigure**：单张方案图，包含：
  - 该图上所有点位的坐标列表（相对于行进场地坐标系）
  - 绘制图形（矩形、圆形等）列表
  - 文本备注列表
  - 分组信息（`QList<Group> groups`）
  - 是否手动修改过（用于后续插值更新）
- **TimelineWidget**：底部时间轴控件，显示各方案图节点，支持点击跳转、插入、删除、调整拍数。

### 4. 场地与网格模块
- **FieldSettings**：存储背景网格颜色/粗细、行进场地经纬线颜色/粗细/加粗规则、数字朝向、缩放比例等。
- **GridRenderer**：负责根据 `FieldSettings` 和当前缩放比例，在 `SchemeScene` 中动态绘制/刷新网格线及外侧数字。不存为图元，而是直接绘制在场景背景层（重写 `drawBackground`）或作为静态图元（效率更高可动态重建）。

### 5. 编辑与变换模块
- **SelectionManager**：管理当前选中的图元集合（支持框选、套索）。
- **TransformController**：对选中的点位（`PointItem`）执行旋转、缩放、平移操作，实时更新坐标。
- **GroupManager**：管理分组信息，实现“跟随前进”路径生成与插值算法。

### 6. 动画演示模块（拓展）
- **AnimationPlayer**：基于 `QTimer` 或 `QTimeLine`，按 120bpm 节奏，根据方案图之间的拍数，计算每拍所有点位的插值坐标，并更新 `PointItem` 位置（临时状态，不修改文档数据）。

### 7. 文件与导出模块
- **SchemeSerializer**：负责将 `SchemeDocument` 保存为 JSON 或 XML 文件，以及从文件加载。
- **PdfExporter**：利用 `QPrinter` 和 `QPainter`，将每张方案图的场景渲染为 A4 PDF，支持多页单文件导出。

## 三、关键类设计（伪代码 / 接口示意）

```cpp
// 场地设置
struct FieldSettings {
    QColor bgGridColor; int bgGridWidth;
    QColor fieldLineColor; int fieldLineWidth;
    int boldInterval;      // 每几条线加粗
    QColor boldLineColor;
    int boldLineWidth;
    bool topLabelNormal, leftLabelNormal;
    bool bottomLabelRotated, rightLabelRotated;
    double scale;           // 缩放比例（仅影响网格间距）
};

// 点位
class PointItem : public QGraphicsEllipseItem {
    int id;                 // 唯一编号
    int groupId;            // 所属组，-1表示未分组
    QPointF pos;            // 坐标（行进场地坐标系，单位：米/步）
    // ... 绘制、选择、拖拽逻辑
};

// 方案图
class SchemeFigure {
    int index;                          // 图序号
    bool isManualModified;              // 点位是否手动修改过
    QMap<int, QPointF> pointPositions;  // 点位ID -> 坐标
    QList<QGraphicsItem*> shapes;       // 直线/矩形/圆形等辅助图形
    QList<TextNoteItem*> notes;
    QList<Group> groups;
    // 插值计算：根据上一张图点位（source）和本图点位（target），返回第t拍（0~totalBeats）的坐标
    QMap<int, QPointF> interpolate(const SchemeFigure& prev, int beat, int totalBeats);
};

// 方案文档
class SchemeDocument : public QObject {
    FieldSettings field;
    QList<int> beatsBetween;            // 长度 = figures.size() - 1
    QList<SchemeFigure> figures;
    int totalBeats() const;             // 计算总拍数
    void insertFigure(int pos);         // 在pos位置插入新图，自动处理插值
    void modifyFigure(int index, const QMap<int,QPointF>& newPositions);
    // 当修改某图后，更新后续未手动修改的图
    void propagateChanges(int startIndex);
};
```

### 图形视图框架的集成
- `SchemeScene` 持有指向当前 `SchemeDocument` 的指针，以及当前显示的 `figureIndex`。
- 当切换方案图时，`SchemeScene` 清空并重新构建图元：
  - 根据 `FieldSettings` 绘制静态网格（可放在 `drawBackground` 中）。
  - 加载当前 `SchemeFigure` 中的点位（`PointItem`）、形状、文本。
  - 同时加载上一张图的点位（用半透明样式）。
- 用户在场景中拖拽/添加点位时，实时更新 `SchemeFigure` 的数据，并标记 `isManualModified = true`，同时触发 `propagateChanges`。

## 四、关键技术与实现要点

### 1. 网格绘制与缩放
- **背景网格与行进场地**：在 `SchemeScene::drawBackground` 中，根据 `FieldSettings.scale` 计算实际格线间距，绘制所有线。这样可以保持线宽不受视图缩放影响（因为 `drawBackground` 使用场景坐标系，线宽由画笔决定，视图缩放时线宽不变）。
- **外侧数字**：作为 `QGraphicsSimpleTextItem` 放置在场景边缘，但其位置需要随缩放比例重新计算（或在 `drawBackground` 中直接绘制文本）。

### 2. 点位吸附
- 在 `PointItem` 的 `mouseMoveEvent` 或 `itemChange` 中，当用户移动结束时，计算最近的网格线交点（根据行进场地的经纬线间距），将坐标取整后设置。

### 3. 插入方案图与插值算法
- 在 `SchemeDocument::insertFigure(pos)` 中：
  - 新图 `newFig` 默认 `isManualModified = false`。
  - 获取前一张图 `prev = figures[pos-1]`，后一张图 `next = figures[pos]`（原pos位置的图后移）。
  - 计算 `newFig` 的点位：对每个公共点位ID，按比例 `t = 0.5`（或根据拍数比例，若拍数未知可默认一半）插值坐标。
  - 更新 `beatsBetween` 列表：将原 `beatsBetween[pos-1]` 拆分为两个拍数（例如平均分配），用户可后续手动调整。
- 插值公式：`P = P_prev * (1 - t) + P_next * t`，其中 `t = currentBeat / totalBeats`（总拍数为两张图之间的拍数）。

### 4. 分组与跟随前进
- 组内点序列排序后，领队点移动时，记录其**历史路径**（一组离散点）。
- 跟随算法：第二名点沿着领队的历史路径点依次移动，可使用线性插值或 CatmullRom 样条（弧线模式）。路径点由用户点击确定后存储在组数据中。

### 5. 保存/加载格式
推荐使用 **JSON**（Qt 支持 `QJsonDocument`），结构清晰：
```json
{
  "fieldSettings": {...},
  "beatsBetween": [8,16,8,...],
  "figures": [
    {
      "index":0,
      "manualModified":true,
      "points": {"1":[10.5,20.0], "2":[30.0,40.0]},
      "shapes": [...],
      "notes": [...],
      "groups": [...]
    }
  ]
}
```

### 6. PDF 导出（多页）
- 遍历 `figures`，对每张图构建临时 `QGraphicsScene` 或直接使用主场景，调整视图矩形（`sceneRect`）使行进场地自适应 A4 大小。
- 使用 `QPrinter` 设置输出格式为 PDF，`QPainter` 将场景渲染到打印机。
- 多页通过 `QPrinter::newPage()` 实现。

## 五、扩展性考虑

- **撤销/重做**：可使用 `QUndoStack` 封装对点位移动、插入图等操作。
- **多文档支持**：将 `SchemeDocument` 作为文档类，配合 `QMdiArea` 实现多标签页。
- **动画演示**：`AnimationPlayer` 独立于文档，临时修改场景中点位位置，不触发 `propagateChanges`，可基于 `QVariantAnimation` 实现均匀移动。
