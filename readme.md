# Marching Map

## 项目简介

My Marching Map 是一款面向学生社团的行进管乐队形编排与可视化工具，所有代码与资源均为自主开发，项目完全开源，旨在为高校、社团等非商业场景提供易用、灵活的队形方案编辑与动画演示能力。

此外，本工作将方案图进行序列化、文本化存储，或许在未来可以使用大模型辅助进行半自动化甚至全自动化的行进方案设计。

## 主要功能

- **场地设置**：双层网格设置（底层网格 + 上层场地）、经纬线颜色宽度设置、数字标注、缩放与保存。
- **方案图与时间轴**：以“拍”为单位管理队形变化，支持在任意拍数插入、时间轴可视化。
- **点位绘制与编辑**：支持点、线、矩形、圆、弧、多边形等多种绘制工具，点位自动吸附网格。
- **选择与变换**：支持框选、组选，点位可旋转、缩放、平移。
- **分组与路径跟随**：支持点位分组及“跟随前进”动画，路径可为直线或曲线。
- **点位标号**：每个点唯一编号，编号自动显示。
- **文本备注**：可在画布任意区域添加备注文本。
- **图形导出**：支持方案图导出为A4 PDF。
- **方案保存与加载**：支持完整保存/读取所有设置与方案数据。
- **动画演示**：按设定拍数和速度播放队形变化，支持轨迹显示与逐拍跳转。

## 技术架构

- **开发语言**：python 3.12.10
- **图形框架**：pyQt6（Graphics View Framework）6.11.0
- **数据存储**：JSON
- **PDF导出**：QPrinter + QPainter
